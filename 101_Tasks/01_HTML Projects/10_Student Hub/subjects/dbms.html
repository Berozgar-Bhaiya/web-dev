What Is a DBMS?

A Database Management System (DBMS) is software used to create, store, organize, retrieve, and manage data efficiently. It allows users and applications to interact with databases.

Advantages of DBMS

  • Reduces unnecessary data duplication
  • Improves data consistency
  • Supports data security
  • Allows efficient data retrieval
  • Supports backup and recovery
  • Enables data sharing between users

Types of Databases

  • Relational Database
  • Hierarchical Database
  • Network Database
  • Object-Oriented Database
  • NoSQL Database

Relational Database Model

The relational model organizes data into tables consisting of rows and columns. Tables can be related using keys.

Important Terms

  • Table: A collection of related data.
  • Row: A single record in a table.
  • Column: An attribute of a table.
  • Primary Key: Uniquely identifies each record.
  • Foreign Key: References a key in another table.

Entity-Relationship Model

The Entity-Relationship (ER) model represents entities, their attributes, and the relationships between them.

Main Components

  • Entity: An object or concept being represented.
  • Attribute: A property of an entity.
  • Relationship: An association between entities.

Structured Query Language (SQL)

SQL is used to define, retrieve, insert, update, and delete data in relational databases.

Common SQL Commands

  • SELECT: Retrieves data.
  • INSERT: Adds new records.
  • UPDATE: Modifies existing records.
  • DELETE: Removes records.
  • CREATE: Creates database objects.
  • ALTER: Modifies database structures.
  • DROP: Removes database objects.

Example SQL Query

The following query retrieves all records from a Students table: 

SELECT * FROM Students;

Database Normalization

Normalization organizes database tables to reduce data redundancy and avoid certain data anomalies.

Common Normal Forms

  • First Normal Form (1NF)
  • Second Normal Form (2NF)
  • Third Normal Form (3NF)
  • Boyce-Codd Normal Form (BCNF)

Database Transactions

A transaction is a sequence of database operations treated as a logical unit of work.

ACID Properties

  • Atomicity: All operations succeed or none do.
  • Consistency: Data remains valid according to rules.
  • Isolation: Concurrent transactions are controlled.
  • Durability: Committed changes persist.

Study Tips

  • Practice writing SQL queries regularly.
  • Understand primary keys and foreign keys.
  • Practice drawing ER diagrams.
  • Learn normalization with examples.
  • Understand ACID properties and transactions.
