What Are Computer Networks?

A computer network is a collection of interconnected computers and devices that communicate and share information and resources with one another.

Benefits of Computer Networks

  • Sharing files and information
  • Sharing hardware and software resources
  • Communication between devices
  • Accessing remote information
  • Supporting online services

Types of Networks

  • Personal Area Network (PAN)
  • Local Area Network (LAN)
  • Metropolitan Area Network (MAN)
  • Wide Area Network (WAN)

Network Topologies

Network topology describes how devices are arranged and connected in a computer network.

  • Bus Topology
  • Star Topology
  • Ring Topology
  • Mesh Topology
  • Tree Topology

OSI Reference Model

The OSI model divides network communication into seven layers. Each layer performs specific tasks to support communication between devices.

  1. Physical Layer
  2. Data Link Layer
  3. Network Layer
  4. Transport Layer
  5. Session Layer
  6. Presentation Layer
  7. Application Layer

TCP/IP Model

The TCP/IP model describes the protocols used for communication across interconnected networks, including the internet.

  • Network Access Layer
  • Internet Layer
  • Transport Layer
  • Application Layer

Network Devices

  • Router: Forwards packets between networks.
  • Switch: Connects devices within a local network.
  • Hub: Sends incoming data to connected ports.
  • Modem: Converts signals for a communication connection.
  • Repeater: Regenerates signals to extend their reach.

Network Protocols

Network protocols define rules that allow devices to communicate and exchange data.

  • HTTP/HTTPS: Used to transfer web content.
  • TCP: Provides reliable, ordered data delivery.
  • UDP: Provides connectionless data transmission.
  • IP: Handles addressing and packet routing.
  • DNS: Translates domain names into IP addresses.
  • FTP: Supports file transfer between systems.

IP Addressing

An IP address identifies a device's network interface so that data can be addressed and routed across networks.

Types of IP Addresses

  • IPv4
  • IPv6
  • Public IP Address
  • Private IP Address

Study Tips

  • Understand the seven layers of the OSI model.
  • Learn the differences between TCP and UDP.
  • Practice subnetting and IP addressing.
  • Draw network topologies for better understanding.
  • Revise important protocols and their purposes.
