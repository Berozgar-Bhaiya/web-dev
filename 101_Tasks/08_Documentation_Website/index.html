HTML Documentation

Introduction

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure content on web pages. HTML uses elements and tags to organize headings, paragraphs, images, links, lists, tables, and forms.

Example:


<!doctype html>
<html lang="en">
    <head>
        <meta charset="UTF-8">
        <title>My First Web Page</title>
    </head>
    <body>
        <h1>Hello, World!</h1>
        <p>This is my first HTML page.</p>
    </body>
</html>

This example displays a heading that says “Hello, World!” and a paragraph that says “This is my first HTML page.” The title appears in the browser tab.

HTML Headings

HTML provides six levels of headings, from <h1> to <h6>. The <h1> element represents the highest-level heading, while <h6> represents the lowest-level heading. Headings organize webpage content into sections and make it easier for readers to understand the structure of a page.

Example:

Remember to use < and > when displaying HTML code inside your documentation. 


<h1>Main Heading</h1>
<h2>Section Heading</h2>
<h3>Subsection Heading</h3>
<h4>Level Four Heading</h4>
<h5>Level Five Heading</h5>
<h6>Level Six Heading</h6>

The browser displays six headings with different levels of importance. By default, <h1> usually appears the largest, while <h6> usually appears the smallest.

The heading levels help organize content logically. Choose them according to the structure of your content, not just their default text sizes.

HTML Paragraphs

HTML uses the <p> element to define a paragraph of text. Paragraphs help organize written content into separate blocks, making webpages easier to read and understand. Browsers typically add space before and after paragraphs automatically.

Example:

Use < and > to display the code correctly in your documentation. 


<p>HTML is used to structure web pages.</p>
<p>Paragraphs organize text into readable blocks.</p>

The browser displays two separate paragraphs:

  • HTML is used to structure web pages.
  • Paragraphs organize text into readable blocks.
  • Each paragraph appears as a separate block of text, with space between them by default.

Links

HTML uses the <a> (anchor) element to create hyperlinks. Links allow users to navigate between webpages, open external websites, or jump to a specific section on the same page. The href attribute specifies the destination of a link.

Example:


<a href="https://www.example.com">Visit Example</a>

<a href="about.html">About Us</a>

<a href="#introduction">Go to Introduction</a>
  • Visit Example opens the external website specified in the href.
  • About Us opens the local page named about.html.
  • Go to Introduction jumps to the section whose ID is introduction on the same page.

Links make websites easier to navigate and connect related content.

Images

HTML uses the <img> element to display images on a webpage. The src attribute specifies the image location, while the alt attribute provides a text description of the image. The <img> element is a void element, meaning it does not need a closing tag.

Example:


<img src="images/nature.jpg" alt="A beautiful green forest">

The browser displays the image stored at images/nature.jpg. If the image cannot load, the alternative text “A beautiful green forest” can help users understand what the image represents.

The alt attribute is also important for accessibility, especially for people who use screen readers.

Lists

HTML provides two main types of lists: ordered lists using the <ol> element and unordered lists using the <ul> element. Each list item is defined using the <li> element.

  • Ordered list(<ol>) - Displays items with numbers by default.
  • Unordered list(<ul>) - Displays items with bullet points by default.
  • List item(<li>) - Defines an individual item in a list.

Example:


<h3>Ordered List</h3>
<ol>
    <li>Learn HTML</li>
    <li>Learn CSS</li>
    <li>Learn JavaScript</li>
</ol>

<h3>Unordered List</h3>
<ul>
    <li>Apple</li>
    <li>Banana</li>
    <li>Orange</li>
</ul>

Ordered List

  1. Learn HTML
  2. Learn CSS
  3. Learn JavaScript

Unordered List

  • Apple
  • Banana
  • Orange

Important: The <li> element must be placed inside an ordered or unordered list to define its items.

Tables

HTML uses the <table> element to display data in rows and columns.

  • <table> - Creates a table.
  • <tr> - Defines a table row.
  • <th> - Defines a header cell.
  • <td> - Defines a regular data cell.
  • <thead> - Groups the table's header rows.
  • <tbody> - Groups the main data rows.

Example:

Add this inside your Tables section:


<table border="1">
    <thead>
        <tr>
            <th>Name</th>
            <th>Age</th>
            <th>Course</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Ankit</td>
            <td>20</td>
            <td>CSE</td>
        </tr>
        <tr>
            <td>Rahul</td>
            <td>21</td>
            <td>ECE</td>
        </tr>
    </tbody>
</table>
Name Age Course
Ankit 20 CSE
Rahul 21 ECE

The table displays student information in three columns and two data rows. The border="1" attribute adds a basic border for demonstration purposes.

Important: In modern HTML, table appearance is generally controlled using CSS rather than the border attribute. Since you're currently practising HTML only, you can use this example to understand the table structure.

Forms

HTML forms are used to collect information from users, such as names, email addresses, passwords, and messages. The <form> element creates a form, while different input elements allow users to enter or select information.

  • <form> - Creates a form.
  • <label> - Provides a label for an input field.
  • <input> - Accepts user input.
  • <textarea> - Allows users to enter longer text.
  • <select> - Creates a dropdown list.
  • <option> - Defines an option in a dropdown.
  • <button> - Creates a clickable button.

Example:


<form action="#" method="post">
    <label for="name">Name:</label>
    <input type="text" id="name" name="name" placeholder="Enter your name">
    <br><br>

    <label for="email">Email:</label>
    <input type="email" id="email" name="email" placeholder="Enter your email">
    <br><br>

    <label for="course">Course:</label>
    <select id="course" name="course">
        <option value="cse">CSE</option>
        <option value="ece">ECE</option>
        <option value="eee">EEE</option>
    </select>

    <br><br>

    <label for="message">Message:</label>
    <textarea id="message" name="message"></textarea>

    <br><br>

    <button type="submit">Submit</button>
</form>

The browser displays a form containing:

  • A text field to enter a name.
  • An email field to enter an email address.
  • A dropdown to select a course.
  • A text area to write a message.
  • A Submit button.

Important concepts:

  • The for attribute on a <label> should match the input's id.
  • The name attribute identifies a field when form data is submitted.
  • type="email" provides basic email-format validation.
  • action="#" is only a placeholder here. This example does not send the data to a real server.

Semantic HTML

Semantic HTML uses elements that clearly describe the meaning and purpose of the content they contain. These elements help browsers, search engines, and assistive technologies understand the structure of a webpage.

Common semantic elements include:

  • <header> - Represents introductory content or a page header.
  • <nav> - Contains navigation links.
  • <main> - Contains the main content of a webpage.
  • <section> - Groups related content.
  • <article> - Represents self-contained content, such as a blog post.
  • <aside> - Contains related or supplementary content.
  • <footer> - Represents footer information.

Example:


<header>
    <h1>Code with Beroz</h1>
</header>

<nav>
    <a href="#home">Home</a>
    <a href="#about">About</a>
</nav>

<main>
    <section>
        <h2>Web Development</h2>
        <p>Learn the basics of building websites.</p>
    </section>

    <article>
        <h2>My First Blog Post</h2>
        <p>This is an example of an article.</p>
    </article>

    <aside>
        <p>Related resources and links.</p>
    </aside>
</main>

<footer>
    <p>Copyright 2026 Code with Beroz.</p>
</footer>

The browser displays a webpage with:

  • A header containing the website title.
  • A navigation area with Home and About links.
  • Main content with a Web Development section.
  • A separate article containing a blog post.
  • An aside containing related information.
  • A footer displaying copyright information.

Important: Semantic elements describe the meaning of content, not its visual appearance. Without CSS, the browser generally displays these elements as block-level sections, and they won't automatically look like a styled website.
