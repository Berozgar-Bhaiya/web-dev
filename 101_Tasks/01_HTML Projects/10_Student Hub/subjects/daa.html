What Is DAA?

Design and Analysis of Algorithms is a computer science subject that focuses on creating algorithms and evaluating their efficiency in terms of time and space complexity.

Algorithm Analysis

Algorithm analysis helps us understand how the running time and memory requirements of an algorithm change as the input size increases.

Time Complexity

Time complexity describes how the number of operations performed by an algorithm grows with the input size.

Space Complexity

Space complexity describes how much memory an algorithm requires during execution.

Asymptotic Notations

  • Big O (O) - Upper bound
  • Big Omega (Ω) - Lower bound
  • Big Theta (Θ) - Tight bound

Example: Finding the Largest Number

Consider a list of numbers. An algorithm can find the largest number by comparing each element with the current largest value.

  1. Assume the first number is the largest.
  2. Compare it with each remaining number.
  3. Update the largest value whenever a bigger number is found.
  4. Return the largest value.

Time Complexity: O(n)
